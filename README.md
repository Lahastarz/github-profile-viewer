# GitHub Profile Viewer

A web app to search any GitHub user and display their profile stats and top repositories.

## Features
- Search any GitHub username
- Displays avatar, bio, followers, following, public repos
- Shows top 5 most recently updated repositories
- Links directly to GitHub profile and each repo

## Tech Stack
- HTML, CSS, JavaScript
- GitHub Public API (no API key required)
